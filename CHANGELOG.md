# Changelog

## v0.1.0 — 2026-11-03

First Keebling release.

- ESP32-S3 USB HID bridge: keyboard, mouse, and consumer/media keys over WiFi.
- Browser remote: touchpad, on-screen keyboard, macro Deck, and Setup.
- No software on the target; works at the login screen, in the BIOS, and in recovery.
- QR + 12-character code pairing; SoftAP or station mode.
- 160×80 LCD status and QR screens; BOOT button gestures and panic release.
- Keebling identity: device UI, favicon, PWA icons/manifest, amber accent, LCD mark.
- GitHub Pages landing page at <https://amoshydra.github.io/keebling/>.
