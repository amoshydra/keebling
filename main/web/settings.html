Device

Product name — the device name the host shows (USB string 2)
Manufacturer (USB string 1)
Interface label (USB string 4 — cosmetic)

ASCII only, up to 31 characters — anything else is replaced with “?”. Both take effect after a restart, and the host must re-read the USB descriptors (replug the dongle).

Screen

Custom text (the third BOOT screen)

Shown on the LCD as 10 lines of 26 characters, so one screen holds 260. Enter starts a new line; longer lines wrap at a space, and a word with no space in it is cut. Plain ASCII only — the font has 96 glyphs, so anything else shows as “?” (one per byte: an em dash is three). Anything past the tenth line is dropped and marked with “...”. Leave it empty and the screen stays out of the BOOT cycle.

Custom image (the fourth BOOT screen)

checking the device…

The preview above is the dithered 160×80 copy the device will draw, not your original file. A colour photo is converted to greyscale rather than reproduced, and the panel is run inverted and does no gamma correction, so mid-greys are expected to look flat. An image of a different shape is scaled to fill the panel and cropped. With no image stored, this screen stays out of the BOOT cycle.

Seconds without a button press before the display blanks. Set to 0 to leave it on. A tap of BOOT wakes it; a further tap cycles between the pairing QR, the status screen and the custom text.

Touchpad

Gestures: one finger moves and taps to click · two fingers scroll and tap to right-click · three fingers drag (press, move, release).

Typing

Lower this if the target drops characters. Assumes a US QWERTY layout on the host.

Exactly what the device reports to the operating system: the report descriptor it hands over at enumeration, plus the interface parameters from the configuration descriptor.
