UI files

Each file the device serves has a built-in copy in the firmware. Uploading one here replaces the built-in copy until it is reset; resetting deletes the uploaded file and the built-in copy is served again. Changes take effect on the next page load — no restart and no reflashing.

A bad upload can break a page, but not permanently: the built-in copies are still in the firmware. This page (ui.html) keeps working even if index.html is broken, so a broken index.html can be reset from here. If ui.html itself is broken, the settings page's “Reset UI to built-in” button restores every built-in copy.

How an update goes

Edit the file on this phone or on a computer, then upload it here and reload the other page. Nothing needs to be reflashed.

An upload is written in one piece: if the transfer is interrupted, the previous copy keeps being served, so a dropped connection cannot leave a half-written page behind.
