Macros

A macro is text typed into the host, with braced tokens for keys that are not characters: {SEARCH}chrome{ENTER} presses the Search media key, types “chrome” and presses Enter. Text assumes a US QWERTY layout on the host.

Grammar

Anything outside braces is typed as literal text. A literal brace is written {{ or }}. Tokens are not case sensitive.

Keys {ENTER} {TAB} {ESC} {BKSP} {DEL} {INS} {UP} {DOWN} {LEFT} {RIGHT} {HOME} {END} {PGUP} {PGDN} {SPACE} {F1} … {F12}
Modifier combinations — CTRL, SHIFT, ALT, CMD, then a key or one character {CTRL+C} {CMD+SPACE} {CTRL+ALT+DEL} {CMD+SHIFT+4}
Media and browser {PLAYPAUSE} {PLAY} {PAUSE} {NEXTTRACK} {PREVTRACK} {STOP} {VOLUMEUP} {VOLUMEDOWN} {MUTE} {SEARCH} {CALC} {BROWSERHOME} {BROWSERBACK} {BROWSERFORWARD}
Delay {WAIT:500} — milliseconds, up to 60000
